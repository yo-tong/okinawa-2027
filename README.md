# 沖繩之旅 2027｜GitHub Pages 手機網站

零建置的沖繩旅行手帳。可在本機直接開啟 `index.html`。部署時將 `index.html`、`base.css`、`journal.css`、`trip-data.js`、`app.js`、`robots.txt` 與整個 `assets/` 目錄一併放到 GitHub Repository 根目錄，再於 Settings → Pages 啟用 main / root。

## 功能

- 每日行程、回程交通卡、景點搜尋、官方與預訂連結
- 三人預算即時計算與瀏覽器本機保存
- 出發前確認清單、行李清單、文字版匯出與列印
- 可直接開啟指定日期，例如 `#days/2027-01-13`。部署後可分享完整網址，本機檔案連結適用於同一台裝置。
- 響應式手機介面、鍵盤操作與 reduced-motion 支援

## 注意事項

網站仍是公開網址；`noindex` 與 `robots.txt` 不能當作隱私防護。請勿加入護照、訂房編號或其他敏感資料。2027 年航班、巴士班次、票價與營業資訊需在出發前重新核實。
